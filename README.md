# Decode Labs E-commerce Data Analysis

## Project Overview
This project focuses on analysing an e-commerce dataset to uncover insights into sales performance, customer purchasing behaviour, product performance and order trends.

The analysis was carried out using Microsoft Excel and Microsoft SQL Server (SSMS) to explore the dataset, perform calculations and generate business insights.

## Tools Used
- Microsoft Excel
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)

## Dataset Overview
The dataset contains 1,200 e-commerce order records with 17 columns, including:
- Order ID and Date
- Customer ID
- Product
- Quantity
- Unit Price
- Total Price
- Order Status
- Payment Method
- Referral Source
- Shipping Information

## Analysis Performed

**Microsoft Excel**
- Data cleaning and preparation.
- Exploratory Data Analysis (EDA).
- Product and customer analysis.
- Order status and payment method analysis.
- Revenue and sales performance analysis.
- Data visualisation and business recommendations.

**SQL Server**
- Data retrieval using `SELECT`.
- Data filtering using `WHERE`.
- Sorting records using `ORDER BY`.
- Grouping data using `GROUP BY`.
- Aggregations using `COUNT()`, `SUM()` and `AVG()`.
- Customer order frequency analysis.
- Product revenue and order status analysis.

## Key Findings
- Chairs recorded the highest revenue and units sold.
- The dataset contained 250 cancelled orders and 247 returned orders.
- Instagram recorded 259 referral orders.
- Most customers placed only one order.
- The highest recorded customer order frequency was two orders.

## Repository Contents
- `Explanatory data analysis.xlsx` – Excel workbook containing the EDA, product and customer analysis, and recommendations.
- `DecodeLabs_Ecommerce_Analysis.sql` – SQL queries used for the analysis.
- `SQL Screenshots/` – screenshots showing SQL query execution and results.

## Conclusion
The analysis provided insights into product performance, revenue, customer purchasing behaviour and order fulfilment. The findings were used to develop recommendations aimed at improving sales performance, customer retention and overall business operations.
